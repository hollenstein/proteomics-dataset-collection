# Proteomics Dataset Collection

A community collection of small, reusable proteomics datasets for software development, testing, examples, and education.

This project provides a way to organize, describe, version, and distribute datasets while allowing the underlying files to remain hosted by existing public repositories.

A particular focus is the creation and annotation of very small raw files and search results for CI testing, software development, and compatibility testing.

## Project status

This is the initial development repository for the project. The project structure, specifications, tooling, and long-term organizational home are still being developed.
